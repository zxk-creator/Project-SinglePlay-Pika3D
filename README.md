## 1. 项目简述与目的

本项目是对经典游戏 **《皮卡堂3D》** 的本地化复刻：将原版游戏的美术资源与玩法框架，重制为一款完全离线、单机可玩的 3D 社区游戏。

**项目目的：**

- 🎮 **复活经典** —— 皮卡堂服务器停运后，玩家再也无法登录原版游戏。本项目让这份回忆在本地继续延续。
- 🏠 **离线可玩** —— 不联网、不排队、不氪金，随时打开随时玩，所有数据保存在本地。
- 🧥 **完整换装** —— 复刻原版骨骼蒙皮换装系统：上装、下装、头发、手套、鞋子、袜子、脸、饰品，实时生效、自由搭配。
- 📚 **学习研究** —— 以经典游戏的架构为教材，实践 Unity URP 渲染、骨骼动画、背包系统等游戏开发技术。

## 3. 技术栈


| 技术                        | 用途              |
| --------------------------- | ----------------- |
| Unity URP                   | 渲染管线（2022+） |
| C#                          | 全部游戏逻辑      |
| Newtonsoft.Json             | 装备配置序列化    |
| Animator                    | 角色动画状态机    |
| Rigidbody + CapsuleCollider | 角色物理控制      |

## 4. 代码目录

```
Scripts/
├── Camera/                 相机：跟随、视角旋转、碰撞回避
├── Character/              角色：移动、跳跃、动画状态、换装入口
│   ├── Equip/              换装系统：骨骼重映射、材质参数、默认着装
│   │   └── Inventory/      背包与装备：物品、容量、装备槽位
│   └── Scene/              场景交互：换装点、传送点、玩家出生点
├── Systems/                全局系统：场景管理、输入、音频、消息、存档
│   └── Scene/              场景切换相关
├── UI/                     界面：标题、换装面板、主信息、消息框、加载
│   ├── ChangeAvatar/       换装界面
│   ├── Components/         通用 UI 组件
│   ├── Loading/            加载界面
│   ├── MainInformation/    主信息面板
│   ├── MessageBox/         消息框
│   └── Title/              标题界面
├── Utils/                  通用工具、常量、资源加载辅助
```
